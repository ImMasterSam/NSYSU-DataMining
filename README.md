# 資料探勘 Data Mining - 第三組

## 目的說明

### 製作資料分類器
- 設計資料分類器
- 利用資料集訓練分類器
- 分析病人是否有糖尿病

### 資料集說明

包含資料集 A、B

1. 懷孕了幾次
1. 血液中葡萄糖濃度
1. 血壓 (舒張壓 mm Hg)
1. 皮膚厚度 (三頭肌皮摺厚度)
1. 胰島素濃度
1. BMI 值
1. 糖尿病函數，糖尿病的風險值
1. 年紀
1. 結果 : 0 無糖尿病，1 有糖尿病 -> 分類的目標


## 資料分類演算法

### KNN (K-近鄰演算法)
每筆資料的類別會由最鄰近的 K 個鄰居來決定  
在 K 個鄰居以出現最多次的類別來決定該資料的類別

### Neural Network (類神經網路)
建立神經網路  
利用訓練集訓練神經網路後  
將測試資料送入模型中即可得到該資料的類別

### Linear SVM (線性支援向量機)
將每一筆資料看做一個 p 維向量  
以一個 (p - 1) 維的超平面來將資料切分開來  
藉由資料位置在超平面兩側來判斷資料的類別

### Linear SVM (非線性支援向量機)
Kernel SVM透過核函數將資料映射到高維空間  
使原本不可線性分離的資料變得可分  
在高維空間中尋找一個最佳超平面

### Random Forest (隨機森林)
通過構建多棵決策樹來進行分類或回歸  
每棵樹基於隨機選擇的數據子集和特徵進行訓練  
最終預測結果由所有樹的投票或平均值決定
